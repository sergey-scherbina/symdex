symdex

Structural code intelligence for coding agents, served over MCP. Source and docs: github.com/sergey-scherbina/symdex.

This site is the Ivy repository of the sbt-symdex plugin:

resolvers += Resolver.url("symdex", url("https://sergey-scherbina.github.io/symdex"))(Resolver.ivyStylePatterns)
